# Tanks-War


3D Game engine in early stages under development.

## How to build


Visual Studio 2022(MSVC v142)


## Running

The needed DLL libraries are included DLL folder.
If you got 0xc0150002 when runnning, remove vld depend library from Main.cpp

## Imported Libraries


- Visual Leak Detector(vld) (for meamory leaks)

- DirectXTK (for loading textures)

- ImGui (UI and input handling)

- SFML (audio)
